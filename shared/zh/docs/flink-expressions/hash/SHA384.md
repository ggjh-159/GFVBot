# SHA384

分类：[哈希函数](../index.md#哈希函数) · 别名：—

## 定位与场景

384位SHA-2摘要，96个小写十六进制字符。介于SHA-256与SHA-512之间的档位。

## 用法

签名：`SHA384(s)`

| 参数 | 类型 | 说明 |
|---|---|---|
| s | STRING | 待摘要的字符串 |

返回：STRING；96个小写十六进制字符。

```sql
-- 16行有界bid源：auction BIGINT、bidder BIGINT、price DECIMAL(10,2)、dateTime TIMESTAMP(3)、extra STRING
SELECT auction, bidder, 0.908 * price + 10, SHA384(bid.extra) FROM bid;
```

输出：STRING；每行96个十六进制字符（随行数据变化）。
