# Changelog语义与多重集折叠

## 四个标志

| 标志 | 含义 | 折叠动作 |
|---|---|---|
| +I | 新行插入 | 加入载荷行 |
| -U | 更新前：被替换的行值 | 移除载荷行 |
| +U | 更新后：新行值 | 加入载荷行 |
| -D | 既有行删除 | 移除载荷行 |

## 为什么无需key也能折叠

回撤流里负标志携带的是被撤回的整行，不只是key。因此对载荷做一次普通的多重集折叠即还原最终结果集——不需要主键知识：

```
final = multiset()
for row in stream:
    if flag in (+I, +U): final.add(payload)
    if flag in (-U, -D): final.remove(payload)   # 必须已存在；缺失=流畸形
```

## 折叠覆盖什么、不覆盖什么

- append-only查询（有界source上的纯投影）只产出`+I`——折叠即行集。
- keyed聚合每次变更产出`-U`/`+U`对，窗口关闭时`-D`——折叠得最终表。
- 行序与中间变更次数不参与比较：两次运行可走不同的变更路径（不同算子链）而同样正确。
- 重复行有分量：折叠是多重集，合法含两行相同值的表与只含一份的表不匹配。

## 实际输出的格式要点

print行在TaskManager`.out`日志中形如`+I[a, b, c]`。注意：

- 并发度>1时print行带子任务前缀，形如`3> +I[a, b, c]`——run-sql.sh捕获时统一剥离前缀，折叠与对比只看`FLAG[payload]`。
- CSV字段含`,`或`[]`——只按括号剥离解析（`FLAG[payload]`），绝不先按逗号切分再取载荷。
- NULL渲染：Flink把null字段印成行内的`null`；两栈渲染一致，折叠后的精确字符串对比有效。
- 两栈间DECIMAL与TIMESTAMP的格式差异是真实不一致，不是噪声——如实上报。
