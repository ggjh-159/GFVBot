# SHA384

Category: [Hash](../index.md#hash) | Aliases: —

## Role and scenarios

The 384-bit SHA-2 digest, as 96 lowercase hexadecimal characters. The tier between SHA-256 and SHA-512.

## Usage

Signature: `SHA384(s)`

| Parameter | Type | Description |
|---|---|---|
| s | STRING | The string to digest |

Return: STRING; 96 lowercase hexadecimal characters.

```sql
-- 16-row bounded bid source: auction BIGINT, bidder BIGINT, price DECIMAL(10,2), dateTime TIMESTAMP(3), extra STRING
SELECT auction, bidder, 0.908 * price + 10, SHA384(bid.extra) FROM bid;
```

Output: STRING; 96 hexadecimal characters per row (varying with the row data).
