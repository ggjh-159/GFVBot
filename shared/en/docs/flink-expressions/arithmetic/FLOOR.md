# FLOOR

Category: [Arithmetic](../index.md#arithmetic) | Aliases: —

## Role and scenarios

Returns the largest integer not greater than x; the temporal form `FLOOR(ts TO unit)` truncates a timestamp down to the boundary of the given unit (HOUR, DAY, MONTH, etc.). It is used to align times or values to bucket boundaries.

## Usage

Signature: `FLOOR(x)`; there is also the temporal form `FLOOR(ts TO unit)`

| Parameter | Type | Description |
|---|---|---|
| x | Numeric | Value to round down |
| ts TO unit | TIMESTAMP and time unit | Temporal form: truncates the timestamp down to the boundary of unit (e.g. HOUR, DAY, MONTH) |

Return: The largest integer not greater than x; the temporal form returns the timestamp truncated to the unit boundary.

```sql
-- 16-row bounded bid source: auction BIGINT, bidder BIGINT, price DECIMAL(10,2), dateTime TIMESTAMP(3), extra STRING
SELECT auction, bidder, 0.908 * price + 10, FLOOR(bid.price) FROM bid;
```

Output: The decimal value of each row with the fractional part removed, e.g. 55.67 becomes 55.

Example (first 8 of the 16 source rows, illustrative data; leading columns are input columns, the last column is the result for that row):

| price | FLOOR(price) | Notes |
|---|---|---|
| 55.67 | 55 | The fractional part 0.67 is discarded |
| 12.50 | 12 | The fractional part is discarded |
| 99.99 | 99 | The fractional part is discarded |
| 3.14 | 3 | The fractional part is discarded |
| 61.20 | 61 | The fractional part is discarded |
| 28.05 | 28 | The fractional part is discarded |
| 77.77 | 77 | The fractional part is discarded |
| 45.00 | 45 | Already an integer; the value is unchanged |
