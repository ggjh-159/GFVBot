# RAND

Category: [Arithmetic](../index.md#arithmetic) | Aliases: —

## Role and scenarios

Returns a DOUBLE uniformly distributed over [0, 1). Without a seed it is a nondeterministic function, drawing independently per row; with a seed the draw sequence is reproducible. It is used for sampling, load spreading, and synthetic columns.

## Usage

Signature: `RAND()` or `RAND(seed)`

| Parameter | Type | Description |
|---|---|---|
| seed | BIGINT | Optional random seed; when given, the draw sequence is reproducible |

Return: A DOUBLE within [0.0, 1.0); nondeterministic.

```sql
-- 16-row bounded bid source: auction BIGINT, bidder BIGINT, price DECIMAL(10,2), dateTime TIMESTAMP(3), extra STRING
SELECT auction, bidder, 0.908 * price + 10, RAND() FROM bid;
```

Output: A DOUBLE within [0.0, 1.0); redrawn on every row (nondeterministic).

Example (input → output):

| Input | Output | Notes |
|---|---|---|
| — | 0.5310239745577783 | An example value from one draw; not reproducible |

The output is regenerated on every row (nondeterministic); the value shown here is from a single draw.
