# CEIL

Category: [Arithmetic](../index.md#arithmetic) | Aliases: `CEILING`

## Role and scenarios

Returns the smallest integer not less than x, with CEILING as a synonymous spelling; the temporal form `CEIL(ts TO unit)` rounds a timestamp up to the boundary of the given unit. It is used for capacity, paging, batching, and other scenarios that require rounding up.

## Usage

Signature: `CEIL(x)` or `CEILING(x)`; there is also the temporal form `CEIL(ts TO unit)`

| Parameter | Type | Description |
|---|---|---|
| x | Numeric | Value to round up |
| ts TO unit | TIMESTAMP and time unit | Temporal form: rounds the timestamp up to the boundary of unit (e.g. HOUR, DAY, MONTH) |

Return: The smallest integer not less than x; the temporal form returns the timestamp rounded up to the unit boundary.

```sql
-- 16-row bounded bid source: auction BIGINT, bidder BIGINT, price DECIMAL(10,2), dateTime TIMESTAMP(3), extra STRING
SELECT auction, bidder, 0.908 * price + 10, CEIL(bid.price) FROM bid;
```

Output: The decimal value of each row rounded up to the next integer, e.g. 55.01 becomes 56.

Example (first 8 of the 16 source rows, illustrative data; leading columns are input columns, the last column is the result for that row):

| price | CEIL(price) | Notes |
|---|---|---|
| 55.67 | 56 | Nonzero fractional part, rounded up by one |
| 12.50 | 13 | Nonzero fractional part, rounded up by one |
| 99.99 | 100 | The carry increases the integer part by one |
| 3.14 | 4 | Nonzero fractional part, rounded up by one |
| 61.20 | 62 | Nonzero fractional part, rounded up by one |
| 28.05 | 29 | Nonzero fractional part, rounded up by one |
| 77.77 | 78 | Nonzero fractional part, rounded up by one |
| 45.00 | 45 | Already an integer; the value is unchanged |
