# SHA512

Category: [Hash](../index.md#hash) | Aliases: —

## Role and scenarios

512-bit SHA-2 digest as 128 lowercase hex characters. The strongest of the plain SHA-2 spellings.

## Usage

Input: `SHA512(s)` — s of STRING; returns 128-character STRING.

```sql
-- 16-row bounded bid source: auction BIGINT, bidder BIGINT, price DECIMAL(10,2), dateTime TIMESTAMP(3), extra STRING
SELECT auction, bidder, 0.908 * price + 10, SHA512(bid.extra) FROM bid;
```

Output: STRING; 128 hex characters per row (data-dependent).
