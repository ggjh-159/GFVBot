# SHA384

Category: [Hash](../index.md#hash) | Aliases: —

## Role and scenarios

384-bit SHA-2 digest as 96 lowercase hex characters. Mid-step between SHA-256 and SHA-512.

## Usage

Input: `SHA384(s)` — s of STRING; returns 96-character STRING.

```sql
-- 16-row bounded bid source: auction BIGINT, bidder BIGINT, price DECIMAL(10,2), dateTime TIMESTAMP(3), extra STRING
SELECT auction, bidder, 0.908 * price + 10, SHA384(bid.extra) FROM bid;
```

Output: STRING; 96 hex characters per row (data-dependent).
