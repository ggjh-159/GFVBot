# SHA256

Category: [Hash](../index.md#hash) | Aliases: —

## Role and scenarios

256-bit SHA-2 digest as 64 lowercase hex characters. The default modern fingerprint.

## Usage

Input: `SHA256(s)` — s of STRING; returns 64-character STRING.

```sql
-- 16-row bounded bid source: auction BIGINT, bidder BIGINT, price DECIMAL(10,2), dateTime TIMESTAMP(3), extra STRING
SELECT auction, bidder, 0.908 * price + 10, SHA256(bid.extra) FROM bid;
```

Output: STRING; 64 hex characters per row (data-dependent).
