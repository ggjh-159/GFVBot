# SHA224

Category: [Hash](../index.md#hash) | Aliases: —

## Role and scenarios

224-bit SHA-2 digest as 56 lowercase hex characters. Compact fingerprints with a lower collision chance than MD5/SHA-1.

## Usage

Input: `SHA224(s)` — s of STRING; returns 56-character STRING.

```sql
-- 16-row bounded bid source: auction BIGINT, bidder BIGINT, price DECIMAL(10,2), dateTime TIMESTAMP(3), extra STRING
SELECT auction, bidder, 0.908 * price + 10, SHA224(bid.extra) FROM bid;
```

Output: STRING; 56 hex characters per row (data-dependent).
